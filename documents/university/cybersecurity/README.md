  Below the notes are my solutions to the three lab sets, each a set of
  crypto challenges solved by scripting against a remote server (`pwntools`):

  - **Lab 01, classical ciphers:** Caesar and substitution ciphers, shift
    brute force, and one-time-pad key reuse.
  - **Lab 02, hashing and passwords:** hash matching, MD5 pre-image and
    short-hash brute force, HMAC forgery, and password cracking with a
    wordlist.
  - **Lab 03, public-key crypto:** Diffie-Hellman, RSA key exchange, a leaked
    RSA factor, sign-then-encrypt, and a textbook-RSA bank protocol.

  `lab_utils.py` holds the shared login/receive helpers the scripts import.
